# This project isn't made for actual use

If you want an actual password manager, use KeePassXC or BitWarden.
This project was made to strengthen my skills, it isn't meant to be perfect and it was developped during classes after having done the assignments.
The encryption system is definitely crackable (considering the encryption system is open-source in this repository), but it is safe enough not to be scraped by whatever malware you could install (already better than google's password manager o7)
